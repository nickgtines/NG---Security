Webhook `POST /ingest/crowdstrike` (space auth). Accepts a mocked CrowdStrike Falcon detection, maps it with `normalize_crowdstrike`, extracts IOCs (deduplicated, private IPs dropped), builds a contract-v3 alert record and checks it. Hands either the record or an `invalid` envelope (→ 400) to **Orchestrate**. No CrowdStrike connector is used. `alert.ts` is shared with Ingest Sentinel.
