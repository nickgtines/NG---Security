Updates the DM, comments/tags/prioritizes the Tines case, adds a color-coded Case Note with the final answer (green = confirmed, red = denied; created once per reachout via `note_created`), and replies in the alert thread. Runs only when "Slack interactivity" forwards a click; there is no schedule, so unanswered reachouts are not timed out automatically.

When "Slack interactivity" forwards a **Close Case** click, it sets that Tines case's status to `closed` (skipped if already closed), comments who closed it, and replies in the Slack message's thread. For **Assign to Me**, it adds ngilling@tines.io as an assignee (skipped if already assigned), comments, and replies in the thread.
